# Task 2 – Food Delivery Data Analysis

## Objective
Analyze food delivery data using Python to perform data manipulation,
basic analysis, and data visualization.

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Dataset
The dataset contains 100,000 food delivery records and 23 columns.

## Analysis Performed
- Data exploration
- Data quality checking
- Data manipulation
- Order analysis
- Food item analysis
- City analysis
- Payment method analysis
- Delivery analysis
- Traffic analysis
- Data visualization
